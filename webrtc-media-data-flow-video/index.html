Summary

入门先记住这四类

路径选择和媒体分发不是同一个问题。

06

P2P

一对一直连

优先让两端直接传输媒体，低延迟、低成本。

TURN

直连兜底

直连失败时转发加密媒体包，解决连通性。

SFU

多人互动

按需转发多路 RTP 流，适合低延迟连麦。

MCU + CDN

大众看播

合流生成节目流，再交给 CDN 大规模分发。

一对一看路径，多人互动看 SFU，大规模看播看 MCU 合流和 CDN 分发。
Glossary 1/2

缩写速查：拓扑、转发与清晰度

先把视频里出现的架构名和清晰度控制概念对上。

07
P2P
Peer to Peer
点对点
两端直接传输媒体。
TURN
Traversal Using Relays around NAT
通过中继穿越 NAT
直连失败时转发加密媒体包。
SFU
Selective Forwarding Unit
选择性转发单元
多人互动中按需转发 RTP 流。
Simulcast
Simultaneous Broadcast
同步多码流发送
同时提供多档清晰度。
SVC
Scalable Video Coding
可伸缩视频编码
在同一路码流里提供可选层。
MCU
Multipoint Control Unit
多点控制单元
解码、混音、拼画面、重新编码。
CDN
Content Delivery Network
内容分发网络
把合流后的直播流分发给大量观众。
Glossary 2/2

缩写速查：媒体与网络

这些名词解释媒体包如何被承载、加密、反馈和选路。

08
RTP
Real-time Transport Protocol
实时传输协议
承载音视频媒体包。
SRTP
Secure Real-time Transport Protocol
安全实时传输协议
加密传输 RTP 媒体。
RTCP
RTP Control Protocol
RTP 控制协议
反馈丢包、延迟、码率和关键帧请求。
NAT
Network Address Translation
网络地址转换
会影响端到端连通性。
ICE
Interactive Connectivity Establishment
交互式连接建立
寻找可用网络路径。
